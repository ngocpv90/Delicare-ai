# T23 – Job tự động: API cho frontend (2026-11-17)

Job chạy theo giờ trong tiến trình riêng **AppDelicare.Job**, không chạy trong WebApi. Frontend chỉ cần:
- màn quản trị xem job và chạy tay (**chỉ admin**);
- nút "Hết hạn hợp đồng quá hạn" trên màn hợp đồng (tùy chọn).

Khung cũ (D-30): route `api/<Controller>/<Action>`, form `[FromForm]`, kết quả `Result<T>` / `Results<T>`. Lỗi nghiệp vụ trả HTTP 200 với `responseCode = 400`. Không có quyền → HTTP 403.

File thử: `docs/api-tests/t23-jobs.http`.

## 1. Danh sách job – `GET api/Job/GetAll` (admin)

Không có tham số. Trả `Results<JobInfoModel>`.

```json
{
  "responseCode": 200,
  "totalRecords": 5,
  "listData": [
    {
      "jobCode": "LockOrders",
      "jobName": "Khóa đơn ngày mai",
      "description": "Khóa mọi đơn Đã xác nhận của ngày ăn D+1 …",
      "enabled": true,
      "at": "20:00",
      "nextRunAt": "2026-11-17T20:00:00",
      "lastRun": {
        "jobCode": "LockOrders",
        "runId": "…",
        "trigger": "SCHEDULE",
        "runStatus": "Succeeded",
        "startedAt": "2026-11-16T20:00:03",
        "completedAt": "2026-11-16T20:00:04",
        "rowsProcessed": 12,
        "targetDate": "2026-11-17T00:00:00",
        "message": "Khóa 12 đơn ngày 17/11/2026"
      }
    }
  ]
}
```

Ý nghĩa các trường:
- **Giờ:** `at`, `nextRunAt` và `startedAt` theo giờ Việt Nam.
- **Trước lần chạy đầu:** `lastRun` = `null`.
- **`trigger`:** `SCHEDULE` = Job tự chạy theo giờ; `MANUAL` = admin bấm chạy.
- **`runStatus`:**

| Mã | Nhãn gợi ý | Màu gợi ý |
|---|---|---|
| `Running` | Đang chạy | xanh dương |
| `Succeeded` | Thành công | xanh lá |
| `Skipped` | Bỏ qua (nghiệp vụ từ chối / không có gì để làm – xem `message`) | vàng |
| `Failed` | Lỗi | đỏ |
| `Locked` | Đang chạy ở nơi khác – bỏ qua | xám |

- **`targetDate`:** ngày nghiệp vụ mà job xử lý, ví dụ ngày ăn được khóa đơn.
- **`message`:** tóm tắt kết quả hoặc lý do bỏ qua, bằng tiếng Việt.

## 2. Chạy tay – `POST api/Job/Run` (admin)

Form: `jobCode`. Các mã: `LockOrders`, `Mrp`, `LotExpiry`, `ContractExpiry`, `MarkAbsent`.

Kết quả `Result<JobRunResultModel>`, `data` có dạng như `lastRun` ở trên, với `trigger = MANUAL`.

| Trường hợp | Kết quả |
|---|---|
| Thành công | 200, kèm `message` |
| Nghiệp vụ từ chối (`Skipped`) | 200, `data.runStatus = Skipped`, `responseMessage` = lý do (ví dụ "Chưa đến giờ chốt …") |
| Job đang chạy ở nơi khác | 400 "Job đang chạy ở nơi khác – lần này bỏ qua" |
| Job lỗi | 400 "Job … lỗi: …" |
| Mã sai | 400, kèm danh sách mã hợp lệ |

Gợi ý giao diện:
- Hỏi xác nhận trước khi chạy, vì job ghi dữ liệu thật: khóa đơn, tạo đề nghị mua, ghi hao hụt lô, đánh vắng.
- Sau khi chạy, tải lại `GetAll`.

## 3. Hết hạn hợp đồng quá hạn – `POST api/Contract/ExpireOverdue`

Cùng hàm với job `ContractExpiry` lúc 00:30.

| | |
|---|---|
| Quyền | Sửa trên `#/crm-contract` |
| Form | `preview` (true = chỉ liệt kê, không đổi dữ liệu) |
| Hợp đồng bị chuyển | **Hiệu lực** và ngày hết hiệu lực < hôm nay → **Hết hạn** |

`data`:
```json
{ "preview": true, "today": "2026-12-01T00:00:00", "expiredCount": 1, "listContractNumber": ["HD-261101-001"] }
```

## 4. Màn hình gợi ý

**`adm-job`** – "Job tự động" (chỉ admin; menu do anh / admin thêm nếu cần, backend không seed):

| Cột | Nội dung |
|---|---|
| Job | `jobName` + `jobCode` |
| Giờ chạy | `at` |
| Bật | `enabled` – chỉ đọc; đổi trong cấu hình máy chủ |
| Lần chạy kế tiếp | `nextRunAt` |
| Lần gần nhất | thời gian, trạng thái (badge), số dòng, `message` |
| Thao tác | nút **Chạy ngay** |
