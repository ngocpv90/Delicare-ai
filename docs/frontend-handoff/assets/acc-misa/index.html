Mô phỏng D-131 – Kết nối kế toán MISA AMIS

Delicare cấp dữ liệu, MISA AMIS hạch toán. Menu mới Kế toán + 2 luồng vận hành.

  1. Kế toán › Chứng từ kế toán (gửi sang AMIS: Excel / API)
  2. Kế toán › Bảng kê thanh toán – gửi khách xác nhận → phiếu bán tháng
  3. Kế toán › Khớp mã AMIS
  4. Kế toán › Đối chiếu với AMIS
  5. Kế toán › Khóa kỳ & chứng từ điều chỉnh
  6. Kho › Trả hàng NCC
  7. Đóng gói & Giao hàng › Định mức bao bì (tự xuất khi đóng gói)

Còn thiếu (Claude Code vẽ khi làm): 2 khung điện thoại 390px cho Trả hàng NCC và Bao bì.
